# Seyone Chithrananda’s academic website

A small Jekyll site hosted with GitHub Pages.

The original site began from Kian Faizi’s template; the repository retains its original license and history. The current design and content have been rewritten for Seyone’s Stanford PhD work.

The homepage uses `assets/portrait.jpg`, configured by `portrait` in `_config.yml`. Replace that file to update the photo. It appears beside the introduction on larger screens and below it on phones.
