# Seyone Chithrananda’s academic website

A small Jekyll site hosted with GitHub Pages. The current redesign lives on the `redesign/stanford-refresh` branch until it is reviewed and merged.

The original site began from Kian Faizi’s template; the repository retains its original license and history. The current design and content have been rewritten for Seyone’s Stanford PhD work.

To add a new portrait, put the image in `assets/` and set `portrait: "/assets/portrait.jpg"` in `_config.yml`. The homepage will place it beside the introduction on larger screens and below it on phones.
